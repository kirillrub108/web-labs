# Блиц: вопросы 81–90

> 345 · Блиц-опрос

| № | Вопрос | Ответ |
|---|---|---|
| 81 | Что такое сессия? | Данные посетителя на сервере между запросами |
| 82 | Где хранятся сессии? | Таблица `django_session` |
| 83 | Что в браузере? | Cookie `sessionid` с ключом |
| 84 | Где хранится корзина? | В сессии под ключом `'cart'` |
| 85 | Структура корзины? | `{id: {'quantity': n, 'price': 'x'}}` |
| 86 | Почему id — строка? | Ключи JSON — только строки |
| 87 | Почему цена — строка? | `Decimal` не сериализуется в JSON |
| 88 | `session.modified = True`? | Принудительно сохранить сессию |
| 89 | `@require_POST`? | Только POST, иначе 405 |
| 90 | `coerce=int`? | Привести значение формы к целому |
