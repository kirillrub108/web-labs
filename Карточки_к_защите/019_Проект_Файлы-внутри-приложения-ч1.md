# Файлы внутри приложения (1/2)

> 019 · Карта проекта · 2.1. Структура файлов

Файлы внутри приложения:

| Файл | Зачем |
|---|---|
| `models.py` | модели (таблицы БД) |
| `views.py` | представления |
| `admin.py` | регистрация моделей в админке |
| `apps.py` | конфигурация приложения |
| `forms.py` | формы (создаётся вручную) |
