# ЛР 1 · Что такое pip? PATH?

> 034 · ЛР 1. Установка ПО и создание проекта Django · 6 из 14

**Вопрос:** Что такое pip? PATH?

**Ответ:** pip — система управления пакетами Python. PATH — системная переменная со списком папок, где ОС ищет исполняемые файлы по имени команды.
