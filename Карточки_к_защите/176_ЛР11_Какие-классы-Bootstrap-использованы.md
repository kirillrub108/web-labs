# ЛР 11 · Какие классы Bootstrap использованы?

> 176 · ЛР 11. Bootstrap, редактирование и удаление, класс-представление · 8 из 21

**Вопрос:** Какие классы Bootstrap использованы?

**Ответ:** `nav`, `nav-item`, `nav-link`, `flex-column` — меню; `row`, `col-sm-2`, `col-sm-10` — **сетка из 12 колонок** (боковое меню 2/12, содержимое 10/12); `table` — таблица; `btn btn-success`, `btn btn-primary` — кнопки.
