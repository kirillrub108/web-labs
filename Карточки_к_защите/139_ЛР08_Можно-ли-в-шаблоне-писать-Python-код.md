# ЛР 8 · Можно ли в шаблоне писать Python-код?

> 139 · ЛР 8. Шаблоны · 14 из 15

**Вопрос:** Можно ли в шаблоне писать Python-код?

**Ответ:** Нет. Язык шаблонов намеренно ограничен: вывод, условия, циклы, фильтры. Логика должна быть в представлении. Методы без аргументов вызываются без скобок: `{{ user.get_full_name }}`.
