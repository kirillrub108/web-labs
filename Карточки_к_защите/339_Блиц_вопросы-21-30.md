# Блиц: вопросы 21–30

> 339 · Блиц-опрос

| № | Вопрос | Ответ |
|---|---|---|
| 21 | Что такое `ForeignKey`? | Связь «многие-к-одному», внешний ключ |
| 22 | `on_delete=CASCADE`? | Удалить зависимые записи вместе с главной |
| 23 | `on_delete=SET_NULL`? | Обнулить ссылку; нужен `null=True` |
| 24 | Как столбец FK называется в БД? | `<поле>_id` |
| 25 | Что такое view? | Функция/класс: принимает request, возвращает response |
| 26 | Где описаны маршруты? | `urls.py`, список `urlpatterns` |
| 27 | Что такое `ROOT_URLCONF`? | Главный файл маршрутов |
| 28 | Что делает `render`? | Собирает HTML из шаблона и контекста, возвращает ответ |
| 29 | Что такое контекст? | Словарь данных, передаваемый в шаблон |
| 30 | Где указан путь к шаблонам? | `TEMPLATES['DIRS']` |
