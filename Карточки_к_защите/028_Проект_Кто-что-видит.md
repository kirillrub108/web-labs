# Кто что видит

> 028 · Карта проекта · 2.4. Кто что видит

| Элемент | Условие в шаблоне | Кто видит |
|---|---|---|
| Статистика на главной | `{% if user.is_authenticated %}` | вошедшие |
| «Сейчас на сайте», «Мои заказы», «Выход» | `user.is_authenticated` | вошедшие |
| «Вход» | `{% else %}` | гости |
| «Все заказы» | `user.is_staff` | персонал (admin, Пользователь_1) |
| «Работа со справочниками» | `user.is_superuser` | только admin |

**Важно:** скрыта только *ссылка*. Сами страницы `/detail/`, `/create/`, `/all_borrowed/` открываются по прямому адресу без входа — см. [ловушки в коде](306_Ловушки_Каверзные-места-именно-этого-проекта.md).
