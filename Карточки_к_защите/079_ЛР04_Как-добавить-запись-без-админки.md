# ЛР 4 · Как добавить запись без админки?

> 079 · ЛР 4. Создание приложения. Модели · 12 из 15

**Вопрос:** Как добавить запись без админки?

**Ответ:** `python manage.py shell` — интерактивная консоль Python с загруженным проектом:

```python
from products.models import Product
Product.objects.create(title="Ручка", description="Синяя")
Product.objects.all()
```
