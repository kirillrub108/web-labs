# ЛР 10 · Что такое форма Django и зачем она, если есть HTML `<form>`?

> 156 · ЛР 10. Форма создания записи · 4 из 16

**Вопрос:** Что такое форма Django и зачем она, если есть HTML `<form>`?

**Ответ:** Класс Python, описывающий поля формы. Даёт три вещи: 1) **генерацию HTML** полей; 2) **валидацию** данных на сервере; 3) **очистку** — преобразование строк из запроса в типы Python (`cleaned_data`).
