# ЛР 2 · WSGI и ASGI?

> 057 · ЛР 2. Настройки проекта (`settings.py`) · 15 из 16

**Вопрос:** WSGI и ASGI?

**Ответ:** WSGI (Web Server Gateway Interface) — стандартный интерфейс между веб-сервером и Python-приложением, синхронный. ASGI — его асинхронный преемник (веб-сокеты, async). `runserver` работает через WSGI — в консоли видно `<WSGIRequest: GET '/'>`.
