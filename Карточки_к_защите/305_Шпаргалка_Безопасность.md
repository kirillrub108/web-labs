# Безопасность

> 305 · Сквозные шпаргалки · 4.3. Безопасность

| Угроза | Суть | Защита в Django |
|---|---|---|
| **CSRF** | чужой сайт отправляет форму от имени вошедшего пользователя | `CsrfViewMiddleware` + `{% csrf_token %}` |
| **XSS** | внедрение `<script>` через пользовательский ввод | шаблонизатор автоматически экранирует вывод `{{ }}` (`<` → `&lt;`) |
| **SQL-инъекция** | подстановка SQL в параметры запроса | ORM использует параметризованные запросы |
| **Кража паролей** | утечка БД | хранится только хеш с солью (PBKDF2) |
| **Кликджекинг** | сайт встраивают в невидимый фрейм | `XFrameOptionsMiddleware` |
| **Подделка Host** | | `ALLOWED_HOSTS` |
