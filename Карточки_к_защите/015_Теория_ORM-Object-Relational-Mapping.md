# ORM (Object-Relational Mapping)

> 015 · Теория с нуля · 1.3. Что такое Django

**ORM (Object-Relational Mapping)** — работа с таблицами БД через классы и объекты Python вместо SQL. Класс = таблица, атрибут класса = столбец, объект = строка. `Product.objects.all()` → `SELECT * FROM products_product`.
