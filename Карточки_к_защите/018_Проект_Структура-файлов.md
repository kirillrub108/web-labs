# Структура файлов

> 018 · Карта проекта · 2.1. Структура файлов

```
pythonproject/                     корневая папка (по методичке)
└── venv/                          виртуальная среда (Python + pip + Django + Pillow)
    └── Django/testproject/
        └── WebApp1/               ← BASE_DIR, здесь manage.py
            ├── manage.py          утилита управления проектом
            ├── db.sqlite3         база данных (в git не хранится)
            ├── WebApp1/           пакет настроек проекта
            │   ├── settings.py    настройки
            │   ├── urls.py        главные маршруты
            │   ├── wsgi.py        точка входа для WSGI-сервера
            │   └── asgi.py        точка входа для ASGI-сервера (асинхронного)
            ├── products/          товары, компании, статусы, прайс; админка; формы; регистрация
            ├── pages/             простые страницы (contact, about, social)
            ├── cart/              корзина на сессиях
            ├── profiles/          создано в ЛР 4, пустое, в INSTALLED_APPS НЕ подключено
            ├── templates/         все HTML-шаблоны
            ├── static/images/     статика (заглушка no_images.png)
            └── media/images/      загруженные картинки товаров
```
