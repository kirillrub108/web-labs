# Проект vs приложение

> 016 · Теория с нуля · 1.3. Что такое Django

**Проект vs приложение.** Проект (`WebApp1`) — весь сайт с настройками. Приложение (`products`, `pages`, `cart`) — компонент проекта, решающий одну задачу; подключается в `INSTALLED_APPS`.
