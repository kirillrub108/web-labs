# ЛР 13 · Зачем переопределён `get_queryset`?

> 211 · ЛР 13. Заказы пользователя · 7 из 13

**Вопрос:** Зачем переопределён `get_queryset`?

**Ответ:** По умолчанию `ListView` вернул бы **все** записи модели. Переопределяю, чтобы показать только экземпляры текущего пользователя (`customer=self.request.user`) со статусом 2, отсортированные по дате.
