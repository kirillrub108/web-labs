# ЛР 8 · Где Django ищет шаблоны?

> 133 · ЛР 8. Шаблоны · 8 из 15

**Вопрос:** Где Django ищет шаблоны?

**Ответ:** Сначала в папках из `DIRS`, затем (при `APP_DIRS: True`) в папке `templates` каждого подключённого приложения. Берёт первый найденный.
