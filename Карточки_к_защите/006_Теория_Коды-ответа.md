# Коды ответа

> 006 · Теория с нуля · 1.1. Как вообще работает веб

**Коды ответа**, которые встречаются в проекте:

| Код | Смысл | Где в проекте |
|---|---|---|
| 200 | OK | обычная страница |
| 301 | постоянный редирект | `/detail` → `/detail/` (Django сам добавляет слэш) |
| 302 | временный редирект | `redirect(...)` после добавления в корзину, удаления; переброс на логин |
| 403 | запрещено | POST без `{% csrf_token %}` |
| 404 | не найдено | адреса нет в `urls.py` |
| 405 | метод не разрешён | GET на `/add/1` (там `@require_POST`), GET на `/accounts/logout/` |
| 500 | ошибка сервера | исключение в коде, например `/detail_product/9999` |
