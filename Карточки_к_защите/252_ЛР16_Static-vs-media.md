# ЛР 16 · Static vs media? ⭐

> 252 · ЛР 16. Интернет-магазин: изображения, цены, сессии · 6 из 19

**Вопрос:** Static vs media?

**Ответ:** **Static** — файлы самого сайта, часть кода: CSS, JS, картинки оформления; лежат в `static/`, подключаются `{% load static %}` и `{% static 'путь' %}`. **Media** — файлы, загруженные пользователями/администратором в процессе работы; лежат в `media/`, адрес берётся из `.url`.
