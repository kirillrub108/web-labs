# ЛР 17 · Зачем `self.session.modified = True`?

> 285 · ЛР 17. Корзина · 20 из 34

**Вопрос:** Зачем `self.session.modified = True`?

**Ответ:** Django сохраняет сессию, только если заметил изменение, а замечает он только присваивание по ключу верхнего уровня (`session['cart'] = ...`). Изменение вложенного словаря (`cart['1']['quantity'] += 1`) он не видит. Флаг говорит явно: «сохрани».
