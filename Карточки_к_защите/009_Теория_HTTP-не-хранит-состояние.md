# HTTP не хранит состояние

> 009 · Теория с нуля · 1.1. Как вообще работает веб

**HTTP не хранит состояние**: каждый запрос независим, сервер «не помнит» прошлый. Чтобы помнить пользователя, используют **cookie** (маленькие данные, которые браузер хранит и прикладывает к каждому запросу) и **сессии** (данные на сервере, а в cookie — только ключ к ним). На этом держатся вход в систему и корзина.
