# ЛР 5 · Чем `null=True` отличается от `blank=True`? ⭐

> 087 · ЛР 5. Изменение моделей · 5 из 16

**Вопрос:** Чем `null=True` отличается от `blank=True`?

**Ответ:** `null` — про **базу данных**: разрешает хранить в столбце `NULL`. `blank` — про **валидацию форм**: разрешает оставить поле пустым в форме/админке. Часто ставят вместе. Для строковых полей обычно достаточно `blank=True` — пустое значение хранится как пустая строка `''`.
