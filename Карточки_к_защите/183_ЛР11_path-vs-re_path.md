# ЛР 11 · `path` vs `re_path`?

> 183 · ЛР 11. Bootstrap, редактирование и удаление, класс-представление · 15 из 21

**Вопрос:** `path` vs `re_path`?

**Ответ:** `path` — простой синтаксис с конвертерами `<int:id>`, совпадение по **всей строке**. `re_path` — регулярное выражение, совпадение по **поиску подстроки** (нужны `^` и `$`, чтобы ограничить). См. [ловушку №4](312_Ловушки_re_path-без-якорей.md).
