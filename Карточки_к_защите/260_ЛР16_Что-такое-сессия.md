# ЛР 16 · Что такое сессия? ⭐

> 260 · ЛР 16. Интернет-магазин: изображения, цены, сессии · 14 из 19

**Вопрос:** Что такое сессия?

**Ответ:** Механизм хранения данных конкретного посетителя между запросами. HTTP сам состояния не хранит. Работает так: при первой записи в `request.session` Django создаёт запись в таблице `django_session` и отправляет браузеру cookie `sessionid` со случайным ключом. При каждом следующем запросе браузер присылает cookie, `SessionMiddleware` по ключу загружает данные — они доступны как словарь `request.session`.
