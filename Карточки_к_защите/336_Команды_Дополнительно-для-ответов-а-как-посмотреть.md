# Дополнительно (для ответов «а как посмотреть…»)

> 336 · Команды

Дополнительно (для ответов «а как посмотреть…»):

| Команда | Что делает |
|---|---|
| `python manage.py showmigrations` | список миграций и какие применены |
| `python manage.py sqlmigrate products 0005` | SQL конкретной миграции |
| `python manage.py migrate products 0003` | откат до миграции 0003 |
| `python manage.py check` | проверка проекта на ошибки конфигурации |
| `python manage.py changepassword admin` | смена пароля |
| `python manage.py collectstatic` | сбор статики в одну папку для продакшена |
| `pip freeze > requirements.txt` | сохранить список пакетов |
| `deactivate` | выйти из виртуальной среды |
