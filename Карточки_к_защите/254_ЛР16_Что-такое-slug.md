# ЛР 16 · Что такое slug?

> 254 · ЛР 16. Интернет-магазин: изображения, цены, сессии · 8 из 19

**Вопрос:** Что такое slug?

**Ответ:** Часть URL, человекочитаемый идентификатор из букв, цифр, дефисов: `карандаш-простой-hb`. `SlugField` — поле для него. `allow_unicode=True` разрешает кириллицу, `db_index=True` создаёт индекс для быстрого поиска. Заполняется в админке автоматически (`prepopulated_fields`). **В итоговых маршрутах slug не используется** — адрес продукта строится по id.
