# ЛР 5 · Почему при добавлении поля `ves` Django задал вопрос?

> 088 · ЛР 5. Изменение моделей · 6 из 16

**Вопрос:** Почему при добавлении поля `ves` Django задал вопрос?

**Ответ:** В таблице уже были записи, а новое поле обязательное (NOT NULL) и без значения по умолчанию — Django не знает, чем его заполнить в существующих строках. Варианты: 1) ввести разовое значение по умолчанию прямо в консоли; 2) выйти и исправить модель — задать `default=...`, либо `null=True`, либо (для текстового поля) `blank=True`. Я выбрал второй путь: с `blank=True` у `TextField` Django сам подставляет пустую строку и вопроса не задаёт.
