# ORM (1/3)

> 300 · Сквозные шпаргалки · 4.1. ORM

| Задача | Код | SQL |
|---|---|---|
| Все записи | `Product.objects.all()` | `SELECT * FROM products_product` |
| Одна по условию | `Product.objects.get(id=1)` | `... WHERE id = 1` |
| Отбор | `Product.objects.filter(company_id=1)` | `... WHERE company_id = 1` |
| Исключить | `Product.objects.exclude(ves='')` | `... WHERE NOT ...` |
| Сортировка | `.order_by('title')`, `.order_by('-title')` | `ORDER BY title [DESC]` |
