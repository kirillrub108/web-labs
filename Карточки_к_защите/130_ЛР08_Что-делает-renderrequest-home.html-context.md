# ЛР 8 · Что делает `render(request, "home.html", context)`?

> 130 · ЛР 8. Шаблоны · 5 из 15

**Вопрос:** Что делает `render(request, "home.html", context)`?

**Ответ:** Находит шаблон, подставляет в него данные из словаря `context` и возвращает `HttpResponse` с готовым HTML. Три аргумента: запрос, имя шаблона, контекст.
