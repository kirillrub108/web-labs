# Как пользоваться карточками

> 001 · Старт

Это тот же сборник для защиты, нарезанный на карточки: **одна карточка — одна мысль**, на каждую уходит 1–2 минуты.

Всего карточек: 355. Проходи их **по номерам подряд** — порядок идёт от основ к частностям, и почти всё нужное для карточки уже встречалось раньше.

- **Теория** (с 002) — фундамент, без него ответы по лабам не склеятся.
- **Карта проекта** — где что лежит, модели, адреса сайта.
- **ЛР 1–17** — у каждой лабы: «Суть за 30 секунд» → что сделано → код → вопросы → «Самопроверка».
- **Ловушки** — особенности твоего кода, на которых ловят. Выучить обязательно.
- **Отличия, команды, блиц, показ, глоссарий** — финальная подготовка.

⭐ — вопросы, которые почти наверняка зададут (11 шт., список в оглавлении).

В каждой лабе последняя карточка — «Самопроверка»: список вопросов без ответов. Не смог ответить вслух — открой карточку по ссылке.

Пути к файлам в карточках указаны относительно папки проекта `pythonproject/venv/Django/testproject/WebApp1/`.
