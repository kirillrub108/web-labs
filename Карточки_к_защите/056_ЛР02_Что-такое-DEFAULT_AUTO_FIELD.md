# ЛР 2 · Что такое `DEFAULT_AUTO_FIELD`?

> 056 · ЛР 2. Настройки проекта (`settings.py`) · 14 из 16

**Вопрос:** Что такое `DEFAULT_AUTO_FIELD`?

**Ответ:** Тип автоматически создаваемого первичного ключа `id`. `BigAutoField` — 64-битное целое с автоинкрементом. В методичке эта строка есть в `settings.py`; в Django 6.x её в шаблоне нет, потому что `BigAutoField` стал значением по умолчанию (видно в миграциях: `('id', models.BigAutoField(...))`).
