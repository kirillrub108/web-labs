# ЛР 16 · Зачем `if settings.DEBUG: urlpatterns += static(...)`?

> 253 · ЛР 16. Интернет-магазин: изображения, цены, сессии · 7 из 19

**Вопрос:** Зачем `if settings.DEBUG: urlpatterns += static(...)`?

**Ответ:** Сервер разработки сам не раздаёт медиа. Функция `static()` добавляет маршрут `/media/...`, отдающий файлы из `MEDIA_ROOT`. Только в режиме отладки: в продакшене файлы должен отдавать веб-сервер (nginx) — это быстрее и безопаснее.
