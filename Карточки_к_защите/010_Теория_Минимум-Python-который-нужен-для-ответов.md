# Минимум Python, который нужен для ответов

> 010 · Теория с нуля · 1.2. Минимум Python, который нужен для ответов

- **pip** — менеджер пакетов Python: `pip install django`, `pip list`.
- **Модуль** — файл `.py`; **пакет** — папка с `__init__.py`. `from .models import Product` — точка значит «из этой же папки».
- **Класс и наследование:** `class Product(models.Model):` — `Product` получает всё поведение `models.Model` (умение сохраняться в БД и т.д.).
