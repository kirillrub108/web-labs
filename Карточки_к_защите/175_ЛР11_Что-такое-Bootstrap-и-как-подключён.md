# ЛР 11 · Что такое Bootstrap и как подключён?

> 175 · ЛР 11. Bootstrap, редактирование и удаление, класс-представление · 7 из 21

**Вопрос:** Что такое Bootstrap и как подключён?

**Ответ:** CSS/JS-фреймворк с готовыми стилями и компонентами (сетка, таблицы, кнопки, навигация). Подключён в `base.html` через **CDN** — ссылками на файлы на внешнем сервере jsdelivr: `<link>` для CSS и `<script>` для JS. Атрибут `integrity` — контрольная сумма файла: браузер не выполнит файл, если его подменили. Минус CDN — без интернета оформление пропадёт.
