# ЛР 11 · Как работает редактирование?

> 186 · ЛР 11. Bootstrap, редактирование и удаление, класс-представление · 18 из 21

**Вопрос:** Как работает редактирование?

**Ответ:** GET — объект достаётся из БД, его поля подставляются в `value` полей формы. POST — значения берутся из `request.POST.get('title')`, присваиваются атрибутам объекта, `save()` выполняет SQL `UPDATE`, затем редирект на список.
