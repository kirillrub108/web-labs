# URL

> 003 · Теория с нуля · 1.1. Как вообще работает веб

**URL** `http://127.0.0.1:8000/detail_product/1/?x=5`:

| Часть | Значение |
|---|---|
| `http` | протокол |
| `127.0.0.1` | адрес сервера. `127.0.0.1` (он же `localhost`) — «этот же компьютер», запрос никуда в сеть не уходит |
| `8000` | порт — номер «двери» на компьютере, за которой слушает программа. 8000 — порт сервера разработки Django по умолчанию |
| `/detail_product/1/` | путь — по нему Django выбирает, какую функцию вызвать |
| `?x=5` | параметры GET-запроса |
