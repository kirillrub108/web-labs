# ЛР 2 · Параметры settings.py (1/3)

| Параметр | Смысл | Значение у нас |
|---|---|---|

| `SECRET_KEY` | секретный ключ для криптографических подписей: сессии, CSRF-токены, ссылки сброса пароля | сгенерирован |

| `ALLOWED_HOSTS` | с каких доменных имён сайт принимает запросы | `[]` |
| `INSTALLED_APPS` | подключённые приложения | 6 встроенных + `products`, `pages`, `cart` |
