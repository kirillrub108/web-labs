# Язык шаблонов (2/2)

> 304 · Сквозные шпаргалки · 4.2. Язык шаблонов

| Конструкция | Назначение |
|---|---|
| `{% include 'navbar.html' %}` | вставка файла |
| `{% url 'name' arg %}` | адрес по имени маршрута |
| `{% load static %}` + `{% static 'path' %}` | адрес статического файла |
| `{% csrf_token %}` | токен защиты формы |
| `{% with a=b.c %}{% endwith %}` | псевдоним |
| `{# комментарий #}` | не попадает в HTML |
