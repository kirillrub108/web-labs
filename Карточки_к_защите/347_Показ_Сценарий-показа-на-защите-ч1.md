# Сценарий показа на защите (1/3)

> 347 · Сценарий показа на защите

Перед показом: активировать среду, перейти в папку с `manage.py`, запустить `python manage.py runserver`. Держать открытыми VS Code с проектом и SQLiteStudio с `db.sqlite3`.

| Шаг | Что показать | Что сказать |
|---|---|---|
| 1 | `http://127.0.0.1:8000/` гостем | главная, `index_view`; гость видит только приветствие |
| 2 | «Компании…» | обобщённый `ListView`, шаблон по соглашению |
| 3 | «Продукция…» → товар | прайс с картинками из `media/`; `get_absolute_url` |
| 4 | Выбрать количество → «Добавить в корзину» | POST, `csrf_token`, `@require_POST`, редирект |
| 5 | Корзина; добавить ещё раз; удалить | данные в сессии; количества суммируются |
