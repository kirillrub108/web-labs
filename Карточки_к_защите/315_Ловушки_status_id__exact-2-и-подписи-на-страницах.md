# `status_id__exact=2` и подписи на страницах

> 315 · Каверзные места именно этого проекта · ловушка 7

В БД: 1 — «На складе», 2 — «В заказе», 3 — «Продана». Код отбирает статус **2**, то есть «В заказе». Для «Моих заказов» и «Всех заказов» это логично. А на главной строка «Количество продуктов, доступных для заказа» на самом деле показывает число экземпляров **в заказе** — комментарий методички («На складе») не соответствует нашим id статусов.

Общая проблема — «магическое число»: код привязан к id записи в справочнике. Надёжнее `filter(status__name='В заказе')`.
