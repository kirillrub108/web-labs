# ЛР 5 · Изменение `verbose_name` не меняет структуру таблицы — зачем миграция?

> 093 · ЛР 5. Изменение моделей · 11 из 16

**Вопрос:** Изменение `verbose_name` не меняет структуру таблицы — зачем миграция?

**Ответ:** Миграции фиксируют полное состояние модели, а не только SQL-структуру. Миграция 0004 создаётся, но в БД по факту ничего не меняет.
