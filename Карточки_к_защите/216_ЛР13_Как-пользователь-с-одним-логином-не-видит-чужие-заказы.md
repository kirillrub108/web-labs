# ЛР 13 · Как пользователь с одним логином не видит чужие заказы?

> 216 · ЛР 13. Заказы пользователя · 12 из 13

**Вопрос:** Как пользователь с одним логином не видит чужие заказы?

**Ответ:** Фильтрация на сервере по `request.user`. Пользователь не может подменить id в запросе — он берётся из сессии.
