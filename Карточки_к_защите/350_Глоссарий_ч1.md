# Глоссарий (1/6)

> 350 · Глоссарий

| Термин | Значение |
|---|---|
| **Backend / Frontend** | серверная / клиентская (браузерная) часть |
| **CBV / FBV** | представление-класс / представление-функция |
| **CDN** | сеть доставки контента; подключение библиотек с внешнего сервера |
| **Cookie** | небольшие данные, хранимые браузером и отправляемые с каждым запросом |
| **CRUD** | Create, Read, Update, Delete — четыре базовые операции с данными |
| **CSRF** | подделка межсайтового запроса |
