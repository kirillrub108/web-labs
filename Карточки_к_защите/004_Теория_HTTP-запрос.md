# HTTP-запрос

> 004 · Теория с нуля · 1.1. Как вообще работает веб

**HTTP-запрос** состоит из метода, пути, заголовков (в т.ч. cookie) и тела. **HTTP-ответ** — из кода состояния, заголовков и тела (обычно HTML).
