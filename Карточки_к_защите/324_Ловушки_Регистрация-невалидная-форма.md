# Регистрация: невалидная форма

> 324 · Каверзные места именно этого проекта · ловушка 13

При ошибке (пароли не совпали, логин занят) словарь `data` остаётся пустым и страница показывается **без полей и без сообщений об ошибках** (проверено) — нужно заново открыть `/registr/`. Исправление — одна строка `data['form'] = form` перед последним `render`.
