# ЛР 14 · Атрибуты ModelAdmin

> 222 · ЛР 14. Настройка админ-панели · 5 из 15

| Атрибут `ModelAdmin` | Что делает |
|---|---|
| `list_display` | столбцы в списке записей (поля модели или методы) |
| `list_filter` | панель фильтров справа |
| `search_fields` | строка поиска и по каким полям искать |
| `fields` | какие поля и в каком порядке на форме |
| `fieldsets` | разбивка формы на секции с заголовками |
| `inlines` | редактирование связанных записей на этой же странице |
| `prepopulated_fields` | автозаполнение поля из других (slug из title) |
| `ordering`, `list_per_page`, `readonly_fields`, `list_editable` | сортировка, размер страницы, только чтение, правка прямо в списке |
