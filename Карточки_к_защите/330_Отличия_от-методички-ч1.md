# Отличия от методички (1/3)

> 330 · Отличия от методички

Методичка написана под **Django 4.0.3**, проект выполнен на **Django 6.1.1** (ставился актуальный `pip install django`), Python 3.13.

| Что | В методичке | У меня | Почему |
|---|---|---|---|
| Выход из системы | ссылка `<a href="{% url 'logout' %}">` | форма `method="post"` с `{% csrf_token %}` и кнопкой | с Django 5.0 `LogoutView` принимает только POST; GET → 405 |
| `DEFAULT_AUTO_FIELD` | строка в `settings.py` | строки нет | `BigAutoField` — значение по умолчанию |
| `MIDDLEWARE_CLASSES` | так назван параметр | `MIDDLEWARE` | старое название, переименовано ещё в Django 1.10 |
| `index_together` | в `Meta` | написан, но не действует | удалён в Django 5.1; спасает второй `Meta` ([ловушка №1](307_Ловушки_В-модели-Product-два-класса-Meta.md)) |
| `context_processors.debug` | есть в `TEMPLATES` | нет | убран из шаблона проекта |
