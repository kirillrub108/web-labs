# ЛР 17 · Почему ключ — строка `str(product.id)`?

> 283 · ЛР 17. Корзина · 18 из 34

**Вопрос:** Почему ключ — строка `str(product.id)`?

**Ответ:** Сессия сериализуется в **JSON**, а в JSON ключи объектов — только строки. Если положить число, после сохранения и загрузки оно станет строкой, и проверка `in` перестанет находить товар.
