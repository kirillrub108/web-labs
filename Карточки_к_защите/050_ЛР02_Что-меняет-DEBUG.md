# ЛР 2 · Что меняет `DEBUG`?

> 050 · ЛР 2. Настройки проекта (`settings.py`) · 8 из 16

**Вопрос:** Что меняет `DEBUG`?

**Ответ:** При `True` — подробная «жёлтая» страница ошибки с трассировкой и настройками, автоперезагрузка сервера. При `False` — пользователю показывается сухая 404/500, обязательно нужно заполнить `ALLOWED_HOSTS`, статику и медиа должен раздавать настоящий веб-сервер. В продакшене — всегда `False`: страница ошибки раскрывает внутренности проекта.
