# Язык шаблонов (1/2)

> 303 · Сквозные шпаргалки · 4.2. Язык шаблонов

| Конструкция | Назначение |
|---|---|
| `{{ var }}`, `{{ obj.field }}`, `{{ obj.method }}` | вывод (метод — без скобок) |
| `{{ var\|filter:arg }}` | фильтр |
| `{% if %} {% elif %} {% else %} {% endif %}` | условие |
| `{% for x in list %} {% empty %} {% endfor %}` | цикл |
| `{% extends 'base.html' %}` | наследование |
| `{% block name %}{% endblock %}` | заменяемый блок |
