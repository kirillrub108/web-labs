# ORM (3/3)

|---|---|---|
| Удалить | `p.delete()` | `DELETE` |
| Через связь | `filter(company__name='ООО')` | `JOIN` |
| Агрегат | `.aggregate(Count('id'))` | `SELECT COUNT(id)` |
| Обратная связь | `company.product_set.all()` | |
| Список id | `filter(id__in=[1, 2])` | `WHERE id IN (1, 2)` |
